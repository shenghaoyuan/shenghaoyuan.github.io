Research project

Porting an eBPF JIT compiler to RISC-V for Solana

2025–2026

An open source project for Solana, developing a RISC-V backend for its eBPF JIT compiler.

Source code: RISC-V branch Related publication

Overview

The project extends Solana’s eBPF (SBPF) JIT compiler with a RISC-V backend. Its architecture separates a shared JIT translation layer from backend-specific code generation, allowing the x86-64 and RISC-V backends to share instruction dispatch, compilation state, metering logic, and jump management.

The implementation is available in the RISC-V branch of Solana-Multi-JITs.
